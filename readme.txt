Bulk Diffusion: Readme.txt

Title: Bulk Diffusion 0.1a

Task: Massive and Continous Picture Rendering 

Author: Hermann Knopp

Version: 0.1a Date: 31.7.2023

Contact: hermann.knopp@gmx.at

Use: Python 3.10.10 x64/amd64
with additional libraries

you should make an virtual
python environment with venv
if you have more python setups

look at: requirements.txt

Usage: Install Python 3.10.10 x64/amd64

       Install Requirements.txt
      
       Start "cmd" Command Box 
          
       cmd use: pip install -r requirements.txt

       cmd run: python.exe bulk_diffusion.py
      
       Prompt is created automatic...    

       The Wordlists loaded by the Code and the
       GPT Lexart Text Engine will autocomplete
       your prompt for maximizing the Look and
       Style of the rendered Output.  

       The Pictures will saved automatic in your
       specified Folder for later use. 



Files: "bulk_diffusion.py"
 
       Main Python App for Generating
       Pictures in Bulk Continous Mode

       "requirements.txt"

       Libraries Install File

       "words.txt"

       English Words Text File
       for random generating
       Picture Prompt Description

       "categories.txt"

       English Words Text File
       for selecting a Picture
       Prompt Category
      
       "moods.txt"

       English Words Text File
       for tweaking Picture
       Prompt in some creative
       Styles 

       all Words Files can be
       edited and expanded
       with own Words at the
       End of the List 

Hardware Requirements:

       at this Time only
       Nvidia Grafic Cards
       with at least 6GB
       of VRam are supported

       the Code for slow
       CPU Rendering is 
       coming soon.(if i figured it out)

       VRam usage:

       4GB VRam for FP32 Diffuser Model
      
       or:     
  
       2GB VRam for FP16 Diffuser Model

       0.5GB VRam for GPTNeo Text Model

       1 - 1.5GB Ram for Pytorch System Files

       (it is possible to set GPTNeo to CPU
        and Diffuser to GPU Execution but Code
        is still missing in Python File,
        this frees some Amount of VRam)

       CPU only Rendering with 4GB - 6GB Ram is not
       supported today (i am working on it)

Contact me at Github for possible Issues and Errors.
